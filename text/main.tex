2D случай. Есть N тел и M контактов.
Для каждого тела известны:

\begin{itemize}
    \item $m_i$ -- масса.
    \item $I_i$ -- момент инерции.
    \item $f_{ext,i,x}$ -- внешние силы (компонента x).
    \item $f_{ext,i,y}$ -- внешние силы (компонента y).
    \item $\tau_{ext,i}$ -- внешний момент вращения.
\end{itemize}

В $k$-й точке соприкасаются тела $i$ и $j$.
Для каждого контакта известны:

\begin{itemize}
    \item $r_{k,i}$ -- вектор от точки контакта до центра масс $i$-го тела.
    \item $r_{k,j}$ -- вектор от точки контакта до центра масс $j$-го тела.
    \item $n_{k}$ -- нормаль контакта (задает плоскость контакта).
    \item $t_{k}$ -- тангенциальная составляющая контакта (вдоль которой пойдёт сила трения).
\end{itemize}

Для каждой точки соприкосновения мы хотим найти:

\begin{itemize}
    \item $N_k$ -- реакция опоры.
    \item $f_k$ -- сила трения.
\end{itemize}

Для каждого тела хотим найти:

\begin{itemize}
    \item $a_{i,x}$ -- ускорение тела (компонента x).
    \item $a_{i,y}$ -- ускорение тела (компонента y).
    \item $\alpha_{i}$ -- угловое ускорение тела.
    \item $\alpha_{i}$ -- угловое ускорение тела.
\end{itemize}

Если для каждого тела просуммировать все силы и воспользоваться вторым законом Ньютона, то получится:

\[ m_i a_{i,x} = f_{ext,i,x} + \sum_{k} (N_k n_{x,k,i} + f_k t_{x,k,i}) \]
\[ m_i a_{i, y} = f_{ext,i,y} + \sum_{k} (N_k n_{y,k,i} + f_k t_{y,k,i}) \]
\[ I_i \alpha_i = \tau_{ext,i} + \sum_{k} [ (r_{x,k,i} ( N_k n_{y,k,i} + f_k t_{y,k,i} ) - r_{y,k,i} (N_k n_{x,k,i} - f_k t_{x,k,i}) ) ] \]

где $n_{x,k,i}$ -- это компонента $x$ нормали $k$-го столкновения, направленная в сторону $i$-го тела
(т.е. для $j$-го тела будет такая же, но в противоположную сторону).
Аналогично $n_{y,k,i}$ -- это компонента $y$. $(r_{x,k,i}, r_{y,k,i}) = r_{k,i}$.
Суммирование происходит по всем точкам контакта, в которых это тело участвует.

\paragraph{}
Решение должно удовлетворять следующим требованиям:

\begin{itemize}
    \item $N \ge 0$ -- тела не притягиваются.
    \item $a_n \ge 0$ -- одно тело не проникает внутрь другого.
    \item $N \cdot a_n = 0$ --
        если тело $i$ в результате получает толчок, то оно все еще должно касаться тела $j$.
        Если толчок тело $i$ не получило, значит касаться оно и не должно (касания впринципе не было???)
    \item $|f| \le \mu N$ -- сила трения не превышает своего возможного максимума.  
\end{itemize}

\paragraph{}
Будем перебирать $3^M$ вариантов. Для каждого из контактов 3 варианта:

\begin{itemize}
    \item Использовать трение покоя.
        В таком случае ограничения $a_t = 0, a_n = 0$, т.е. тела не двигаются и прижаты друг к другу.
        Остается проверить $N \ge 0, |f| \le \mu N$
    \item Использовать трение скольжения.
        В таком случае ограничения $a_n = 0, |f| = \mu N$, т.е. тела друг к другу прижаты, но двигаются.
        Остается проверить $N \ge 0$.
    \item Контакта нет??
        В таком случае ограничения $N = 0, f = 0$
        Остается проверить $a_n \ge 0$
\end{itemize}

\paragraph{}
Если взять уравнения выше для каждого тела и составить из них систему уравнений, то при подстановке
дополнительных ограничений получится СЛАУ, которую можно попробовать решить.
Если решается и по требованиям проходит, то решение найдено, если нет, то пробуем дальше варианты.

\paragraph{}
Можно записать его в виде матриц:

\[ M a = F_{ext} + J^T \lambda \]

где:
\[
M = 
\begin{pmatrix}
    M_1 \\
    & \ddots \\
    & & M_N
\end{pmatrix}
M_i =
\begin{pmatrix}
    m_i & 0 & 0 \\
    0 & m_i & 0 \\
    0 & 0 & I_i
\end{pmatrix}
\]

\[
F_{ext} = 
\begin{pmatrix}
    F_{ext,1} \\
    \vdots \\
    F_{ext,N}
\end{pmatrix}
F_{ext_i} =
\begin{pmatrix}
    F_{ext,x,i} \\
    F_{ext,y,i} \\
    \tau_{ext,i}
\end{pmatrix}
\]

\[
\lambda = 
\begin{pmatrix}
    N_1 \\
    f_1 \\
    N_2 \\
    f_2 \\
    \vdots \\
    N_M \\
    f_M \\
\end{pmatrix}
\]

\[
J =
\begin{pmatrix}
    J_1 \\
    \vdots \\
    J_M
\end{pmatrix}
J_k = 
\begin{pmatrix}
    0 & \dots & n_k^T & (r_{i,k} \times n_k)_z & \dots & -n_k^T & -(r_{i,k} \times n_k)_z & \dots & 0
\end{pmatrix}
\]

\[
a =
\begin{pmatrix}
    a_1 \\
    \vdots \\
    a_N
\end{pmatrix}
a_i =
\begin{pmatrix}
    a_{i,x} \\
    a_{i,y} \\
    \alpha_{i}
\end{pmatrix}
\]

\paragraph{}
Для трехмерного случая всё наверное также, только дополнительно появляется компонента $z$ и ещё две оси вращения.
