Допустим у нас есть какие-то тела и они касаются друг друга в каких-то точках:

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.5\textwidth]{sample.png}
\end{figure}

Тела неподвижны, их скорость равна нулю.
К телам прикладываются какие-то силы (например ускорения свободного падения, отмечены красным).

В каждой точке касания касаются два каких-то тела.
Каждая точка касания имеет ускорение как точка первого тела и как точка второго тела.
Разница этих ускорений -- это относительное ускорение.

В каждой точке касания есть плоскость касания (в двухмерном случае это просто прямая).
У этой плоскости касания есть нормаль касания.

Можно разложить относительное ускорение на соответствующие компоненты (отмечены зеленым).

\paragraph{Непроникновение}

Если нормальная часть относительного ускорения меньше нуля, то тела начинают проникать друг в друга.
Поэтому потребуем, чтобы $a_{n,i} \ge 0$ для каждого контакта.

Это требование мы будем выполнять с помощью прикладывания сил $f_{n,i}$ вдоль нормалей плоскостей касания.
Потребуем для них $f_{n,i} \ge 0$.

Дополнительно потребуем $f_{n,i} \cdot a_{n,i} \ge 0$.
Это значит, что кто-то из двух обязательно равен нулю.
Например, если в ходе разрешения каких-то касаний так получилось, что в $i$-ом касании
уже $a_{n,i} > 0$, то силу $f_{n,i}$ прикладывать НЕ НУЖНО.
И наоборот, если прикладываем силу $f_{n,i}$, то прикладываем её ровно настолько, чтобы избавиться
от проникновения, т.е требуем $a_{n,i} = 0$.

Итого получаем требования:

\[
\begin{matrix}
    a_{n,i} \ge 0 \\
    f_{n,i} \ge 0 \\
    a_{n,i} \cdot x_{n,i} = 0
\end{matrix}
\]

где $a_{n,i} = \sum_j A_{i,j} f_{n,j} + b_i$.

Это дело можно переписать в матричном виде:

\[
\begin{matrix}
    Af + b \ge 0 \\
    f \ge 0 \\
    f^T (Af + b) = 0
\end{matrix}
\]

Это называется Linear Complementarity Problem (LCP), Линейная задача о дополнении.
Она решается например с помощью Projected Gauss Seidel. Это обычный метод Гаусса-Зейделя,
только на каждой итерации дополнительно $x$ загоняется в своё ограничение $(x \ge 0)$.

\paragraph{Трение}

Силы трения направлены вдоль тагненциального направления и с ними всё гораздо сложнее.
Если попробовать сформулировать требования к силам трения, то LCP не получается:

\[
\begin{matrix}
    |f_{t,i}| \le \mu f_{n,i} \\
    a_{t,i} \cdot sgn(f_{t,i}) \le 0 \\
    (\mu f_{n,i} - |f_{t,i}|) (a_{t,i} sgn(f_{t,i})) = 0
\end{matrix}
\]

Вылезают модули и sgn.

Но есть решение. Можно разбить силу трения на две: $f_{n,i}^+$ и $f_{n,i}^-$.
Обе по величине неотрицательные, но направлены в противоположные стороны.

Также заведём новую переменную для каждого контакта: $\beta_i$.
Это будет "индикатор" движения. Равен нулю, если силами трения удалось полностью убрать относительное ускорение вдоль плоскости касания.
Больше нуля, если не удалось.

Тогда условия можно переписать так:

\[
\begin{matrix}
    a_{t,i} + \beta_i \ge 0 && f_{t,i}^+ \ge 0 && (a_{t,i} + \beta_i) f_{t,i}^+ = 0 \\
    -a_{t,i} + \beta_i \ge 0 && f_{t,i}^- \ge 0 && (-a_{t,i} + \beta_i) f_{t,i}^- = 0 \\
    \mu f_{n,i} - f_{t,i}^+ - f{t,i}^- \ge 0 && \beta_i \ge 0 && (\mu f_{n,i} - f_{t,i}^+ - f_{t,i}^-) \beta_i = 0
\end{matrix}
\]

Если прибавить к этому всему условия для непроникновения, и за $f$ взять:

\[\begin{pmatrix}
f_n \\ f_t^+ \\ f_t^- \\ \beta
\end{pmatrix}\]

То эту задачу, удивительно, МОЖНО привести к виду:

\[
\begin{matrix}
    Af + b = 0 \\
    f \ge 0 \\
    f^T (Af + b) \ge 0
\end{matrix}
\]

Готово.

\[
\begin{matrix}
    0 \le a_{n,i} && \perp && f_{n,i} \ge 0 \\
    0 \le a_{t,i} + \beta_i && \perp && f_{t,i}^+ \ge 0 \\
    0 \le -a_{t,i} + \beta_i && \perp && f_{t,i}^- \ge 0 \\
    0 \le \mu f_{n,i} - f_{t,i}^+ - f{t,i}^- 0 && \perp && \beta_i \ge 0
\end{matrix}
\]
